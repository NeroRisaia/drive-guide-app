    データの出典とライセンス

    地図・地点データ: © OpenStreetMap contributors（Open Database License (ODbL) 1.0）。観光スポットは OpenStreetMap から抽出した派生データベースで、Open Database License (ODbL) 1.0 で提供しています（データ JSON）。アプリに同梱しており、現在地の周りの分だけを端末で読み込みます。

    対象: OpenStreetMap の tourism=attraction（観光名所）・museum（博物館）・gallery（美術館）・viewpoint（展望地）・zoo（動物園）・aquarium（水族館）・theme_park（テーマパーク）と historic=castle（城・城跡）。名称の登録がないもの（展望地を除く）と、access=private／no のものは除いています。

    スポットの説明文: Wikipedia日本語版（CC BY-SA 4.0、記事ごとの出典は説明の下に表示）または OpenStreetMap の description タグ。名称での検索のため、別の記事が表示される場合があります。経路案内は Google マップを開きます。
